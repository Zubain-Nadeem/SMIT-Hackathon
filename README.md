# 🚀 PitchGen AI

PitchGen AI helps founders instantly turn their startup ideas into polished investor-ready pitches — complete with a name, tagline, elevator pitch, problem, solution, and target audience.  
It also lets users generate a live **landing page** from each pitch.

---

## 🧠 Features

- ✨ AI-generated startup pitches using Google Gemini
- 💾 Secure user authentication with Firebase
- 📄 Save and view previous pitches from your dashboard
- 🎨 Auto-generate landing pages from your pitches
- 📤 Export pitches as PDF
- 🌙 Clean dark mode UI built with Tailwind CSS + React

---

## 🛠️ Tech Stack

| Category | Technology |
|-----------|-------------|
| Frontend | React, Vite, Tailwind CSS |
| Backend | Serverless API (Node.js / Vercel Functions) |
| AI | Google Gemini API |
| Database & Auth | Firebase |
| PDF Generation | jsPDF |
